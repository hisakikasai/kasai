# 資格マネージャー

受験日・勉強予定と進捗・経費申請状況をまとめて管理する、スマホ向けの資格管理アプリ（PWA）です。
毎日続けやすいように「開いて 1 タップで記録」できることを重視しています。

## 主な機能

| 項目 | 内容 |
| --- | --- |
| 受験日 | 受験日・時刻・会場・予約番号を登録。ホームに「あと◯日」を表示。`.ics` / Google カレンダーに追加（1 週間前・前日リマインダー付き） |
| 勉強予定・進捗 | 期限つきの予定リスト（チェックで完了）。受験日から逆算した週ごとの予定枠を自動作成。目標学習時間に対する進捗と「1 日あたり必要な学習時間」を計算 |
| 経費申請 | 受験料・教材費ごとに「申請済み」チェック。未申請 → 申請済み → 承認済み → 精算完了、領収書保存、申請期限を管理 |
| 毎日の記録 | ホームで資格を選び 15/30/60 分をタップして記録。昨日分の後追い記録も可。連続記録日数（🔥）と学習カレンダー（ヒートマップ） |
| 外部サイト連携 | 資格ごと・共通の学習サイト URL を登録（AWS Skill Builder などのプリセットあり）。⏱ ボタンでサイトを開くと同時に学習タイマーが開始し、戻って「終了して記録」で自動記録 |
| 確認事項 | 経費の未申請・期限超過、期限切れの予定、受験日未設定・経過、資格の有効期限、バックアップ未実施を自動で警告 |
| データ | JSON バックアップ / 復元、学習記録の CSV 出力 |

## 使い方

```bash
npm install
npm run dev      # 開発サーバー
npm test         # ユニットテスト
npm run build    # dist/ に本番ビルド
```

`main` ブランチに push すると GitHub Actions でテスト・ビルドし、GitHub Pages に公開します
（リポジトリの Settings → Pages → Source を「GitHub Actions」に設定してください）。
公開した URL をスマホで開き「ホーム画面に追加」すると、アプリとして起動・オフライン利用できます。

## 技術構成

- React 19 + TypeScript + Vite
- データ保存: ブラウザの localStorage（サーバー不要・無料で運用可能）
- PWA: `public/manifest.webmanifest`, `public/sw.js`
- ルーティング: ハッシュルーティング（GitHub Pages のサブパスでも動作）

## 考慮した点・今後の検討事項

要件（受験日 / 勉強予定と進捗 / 経費申請チェック / 外部サイト URL）に加えて、以下を検討しました。

### 対応済み

- **経費は「申請済み」だけでは足りない**: 承認・精算完了まで追わないと入金漏れに気づけないため 4 段階に。領収書の保存有無、申請期限、「合格時のみ支給」などを書ける備考も用意。
- **受験後のこと**: 合否・スコアの記録、受験日を過ぎたら結果入力を促す警告、資格の**有効期限**（AWS は 3 年）と期限 90 日前の更新リマインド。
- **受験予約**: 予約番号・会場・時刻、受験 30 日前に「予約済みか」を確認。
- **継続しやすさ**: 1 タップ記録、昨日分の後追い記録、今日まだ記録していなくても連続記録が途切れて見えない表示、タイマーの止め忘れ対策（3 時間超で確認）。
- **外部サイトの進捗は自動取得できない**: AWS Skill Builder などは個人の学習進捗を取得できる公開 API がないため、「サイトを開くと同時にタイマー開始 → 戻って記録」で手間を減らす方式にしています。
- **URL の安全性**: `javascript:` などを弾き http(s) のみ許可。外部リンクは `noopener noreferrer` で開く。
- **日付の扱い**: UTC ではなく端末のローカル日付で日別集計（深夜の記録が前日扱いになる問題を回避）。
- **データ消失**: 端末内保存のため、バックアップ / 復元と、30 日バックアップしていない場合の警告を用意。

### 未対応（必要なら次の段階で）

- **複数端末の同期・ログイン**: PC とスマホで同じデータを使いたい場合は Supabase / Firebase などのバックエンドが必要。
- **プッシュ通知**: 「今日まだ勉強していません」の通知はサーバー側の Web Push が必要。現状はカレンダー連携のリマインダーで代替。
- **チーム・会社での利用**: 上長の承認フローや、経費精算システムとの連携は未対応（会社の精算ルール・申請期限の確認が必要）。
- **再受験の履歴**: 現状は 1 資格 1 受験。不合格→再受験の履歴を残したい場合は「受験回」を別データにする。
- **領収書の画像添付**: localStorage の容量制限（約 5MB）があるため未対応。IndexedDB かクラウドストレージで対応可能。
